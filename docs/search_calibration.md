## 4. Обоснование выбора порога

По результатам эксперимента установлен порог семантической релевантности 0.25.

Выбранное значение позволяет:

- сохранить результаты всех пяти целевых запросов;
- исключить результаты двух нецелевых запросов;
- находить перефразированные характеристики;
- уменьшить потери полезных фрагментов по сравнению с первоначальным порогом 0.50.

Порог применяется к семантическому поиску и векторной составляющей гибридного поиска. Лексическая составляющая гибридного поиска не ограничивается данным порогом.

## 5. Ограничения эксперимента

- Небольшой объём корпуса документов.
- Ограниченное количество экспериментальных запросов.
- Отсутствие полной экспертной разметки релевантности.
- Пересечение оценок релевантных и нерелевантных фрагментов.
- Порог релевантности не обеспечивает защиту от Prompt Injection.

## 6. Принятое решение

В файле app/core/config.py установлено значение search_similarity_threshold = 0.25.

Выбранный порог является предварительным и подлежит повторной калибровке при существенном расширении корпуса документов или замене модели эмбеддингов.
